# Task 04 - Angajații companiei

Programul afișează informații despre angajați și salariile lor.

## Rulare

Din folderul principal: `node task-04/main.js`.

## Datele angajaților

Lista conține șapte angajați. Fiecare are `id`, `name`, `department`, `salary` și `experience`.

## Departamente

Angajații pot fi filtrați sau grupați după departament. Exemplul afișează și angajații din IT.

## Salarii

Se calculează salariul mediu. Angajații cu mai mult de 3 ani de experiență primesc o mărire de 10%.
