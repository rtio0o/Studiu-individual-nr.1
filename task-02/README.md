# Task 02 - Catalogul elevilor

Programul afișează și gestionează o listă de elevi.

## Rulare

Din folderul principal: `node task-02/main.js`.

## Elevi

Fiecare elev are un `id`, un `name` și o `grade`. Lista inițială conține cinci elevi.

## Calcule

În `utils.js`, `calculateSum()` calculează suma, iar `calculateAverage()` calculează media. Pentru o listă goală, media este 0.

## Funcțiile pentru elevi

În `students.js` se află funcțiile pentru afișare, căutare și adăugare. `addStudent()` întoarce o listă nouă.

## Căutare

Elevul este căutat după `id`. Dacă nu există, funcția generează o eroare, iar `try/catch` afișează mesajul.

## Rezultate

Media inițială a clasei este 8.00. Sunt afișați elevii cu nota de minimum 8, apoi este adăugat un elev nou.
