# JavaScript Modern Lab 2

Partea a doua a laboratorului JavaScript. Fiecare exercițiu se află într-un folder separat și poate fi rulat cu Node.js.

## Cerințe

- Node.js 18 sau mai nou
- Nu sunt necesare biblioteci externe.

## Rulare

Din folderul proiectului, rulați una dintre comenzile:

```bash
npm run task:01
npm run task:02
npm run task:03
npm run task:04
```

Sau direct cu Node.js, de exemplu:

```bash
node task-03/main.js
```

## Structură

- `task-01` — note: `filter()`, `map()` și `reduce()`
- `task-02` — module ES și gestionarea elevilor
- `task-03` — coș de cumpărături cu module și funcții pentru produse
- `task-04` — gestionarea angajaților și raport final

Mesajele din consolă sunt în română, iar numele funcțiilor sunt în engleză pentru a fi ușor de urmărit în cod.
